# Week 1 – HTML Portfolio

## Objective
Build a personal portfolio using **semantic HTML5**.

## Requirements
- Use semantic elements (`header`, `nav`, `main`, `section`, `footer`)
- Include at least:
  - About section
  - Projects section
  - Skills section
  - Contact section
- Use headings correctly
- Include at least 3 images with `alt` attributes
- Validate HTML using W3C Validator

## Submission
Push your completed code to GitHub.
